Not sure where to begin?

Read the Python Quick Start, then FastAPI. Those two carry almost everything later: the language, and the habit of putting a typed contract in front of your code. Everything after them is a variation on that idea — for a browser, for another program, or for an AI.

The words, before the code

Most of what makes this field sound hard is vocabulary. Eight terms cover nearly every guide here.

🌐 API
A door into your program that other programs can knock on. You write a function; an API makes it callable over the network.
✅ Schema
A written-down shape for data — this field is text, this number is 1 to 5. Declare it once and everything downstream can stop checking.
🔎 GraphQL
One address instead of twenty, where the caller lists the fields it wants and gets exactly those back — no more, no fewer.
🤖 Agent
A model in a loop with tools. It decides which tool to call and when to stop — your code still does the actual work.
🧩 MCP
Model Context Protocol — a standard way to publish tools so any AI client can use them. Write the tool once, not once per assistant.
🔗 A2A
Agent-to-agent. MCP gives one agent tools; A2A lets separately built agents discover each other and delegate work.
🏗️ Infrastructure as code
Servers and databases described in files you commit, instead of buttons someone clicked once and cannot remember.
☁️ AgentCore
AWS's managed home for agents in production — isolated runtime, memory, identity and tool gateways you would otherwise build yourself.

A path through it

Read in this order and each step uses the one before it. Skip freely — every guide stands alone.

1

Learn the language

Python — enough to read every other page here without guessing.

2

Put it behind an address

FastAPI, then GraphQL — the same data served two ways, so the trade-off becomes obvious rather than theoretical.

3

Hand it to an AI

FastMCP publishes the same logic as tools an agent can call — no model required in the server itself.

4

Let something decide when to call it

The Strands course builds the agent; A2A is what you reach for when one agent is not enough.

5

Ship it

Terraform describes the cloud it runs on; AWS AgentCore is the managed place to run it.
