4. Control flow

    print("adult")

    print("teen")

for n in nums:               # loop over items
    print(n)

for i in range(3):           # 0, 1, 2

5. Functions

python
def greet(name, excited=False):     # excited has a default
    msg = f"Hello, {name}"
    return msg + "!" if excited else msg

greet("Ada")               # "Hello, Ada"
greet("Ada", excited=True) # "Hello, Ada!"

return hands a value back; print only shows it. Full detail: Functions.

6. Comprehensions (the Pythonic one-liners)

python
squares = [n * n for n in range(5)]          # [0, 1, 4, 9, 16]
evens   = [n for n in range(10) if n % 2 == 0]
lengths = {w: len(w) for w in ["hi", "hey"]} # dict comprehension

A compact way to build a list/dict from a loop. Reach for it when it stays readable.

7. Classes (OOP) in 20 seconds

python
class Dog:
    def __init__(self, name):   # setup, runs on creation
        self.name = name        # this object's data

    def bark(self):
        print(f"{self.name} says woof")

class Puppy(Dog):               # inherits from Dog
    def play(self):
        print(f"{self.name} plays")

Puppy("Milo").bark()   # inherited

self = "this object." Principles: encapsulation, inheritance, polymorphism, abstraction. Full detail: Objects & Classes.

8. Generators & decorators

python
import functools

# generator — yields values one at a time (memory-friendly)
def pending(tasks):
    for task in tasks:
        if not task.done:
            yield task

# decorator — wraps a function to add behaviour (wraps preserves its name)
def log_calls(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        print(f"  · {func.__name__} -> {result!r}")
        return result
    return wrapper

@log_calls
def add(a, b):
    return a + b

You'll see @ everywhere later (@app.get, @tool). These are the exact pending() generator and log_calls decorator used in quickstart/code/python/task_tracker.py. Full detail: Generators · Decorators.
